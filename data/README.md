# Data files

| File | Contents |
| --- | --- |
| `tadf_dataset.xlsx` | Training and cross-validation workbook. Also the default source for new generation runs. |
| `core-structurexlsx.xlsx` | Core and fragment definitions used for feature calculation and scaffold-based generation. |
| `test molecules.xlsx` | External validation molecules and experimental measurements. |
| `learned_substitution_patterns.csv` | Substitution patterns learned for the archived generation run. |

The archived candidate and screening tables are in [reference results](../reference%20results/).

Preserve workbook headers and row order to reproduce the supplied workflows.
